# 条件 DSL 语法

本工作台用中文模板描述策略条件。每条条件是一个独立的字符串，必须逐字符合模板，生成后必须调用 validate_strategy_conditions 校验。

## 入场条件模板

- `收盘价站上N日均线`：收盘价高于 N 日均线，N 为数字（如 收盘价站上20日均线）。
- `量比N日介于A到B`：如 量比2日介于1.2到2.5。
- `流通市值X到Y`：X/Y 可带单位万/亿，如 流通市值10亿到300亿。
- `换手率A%到B%`：如 换手率2%到8%。
- `近N日涨幅介于A%到B%`：如 近5日涨幅0%到12%。
- `近N日涨幅小于X%`：如 近5日涨幅小于12%。
- `近N日主力净流入大于X（万/亿）`：如 近3日主力净流入大于300万。
- `近N日主力净流出大于X（万/亿）`：资金流出过滤。
- `突破N日新高`：如 突破20日新高。
- `MACD柱线大于X`：如 MACD柱线大于0。
- `市场上涨家数占比大于N%`：市场宽度过滤，如 市场上涨家数占比大于55%。

## 离场条件模板

入场模板中 `收盘价跌破N日均线`、`近N日涨幅小于X%`、`近N日主力净流出大于X` 同样可用作离场，另支持：

- `MACD死叉`
- `资金流出`（当日主力净流出）
- `跌破N日低点`
- `创N日新低`

## 校验失败的常见原因

- 数字与单位之间加了空格或用了"万元以上"等模板外写法。
- 把两个条件写进一条字符串（每条只能表达一个条件）。
- 使用了模板中没有的指标（如布林带、KDJ——本地引擎暂不支持）。

## 组合成策略

- 多条入场条件放在同一个 entry_expressions 列表中，回测时为"同时满足"（AND）关系。
- 离场条件同理，任一命中即触发卖出。
- 回测设置：日期区间最长 366 天；自定义股票池最多 50 只；初始资金 1 万到 1 亿。
