# 价值陷阱与价投误区分析

> "便宜"不等于"值得买"。本知识库整理 A 股常见的价值陷阱识别方法，供基本面分析时检索引用。不构成投资建议。

## 什么是价值陷阱

估值看起来便宜（低 PE/PB、高股息），但股价长期不涨甚至阴跌——因为**低估值反映的是基本面持续恶化或结构性衰退**，市场定价并没有错。

## 常见类型与识别清单

### 1. 周期股的"低 PE 陷阱"（A 股最经典）

- 周期股（煤炭、钢铁、航运、化工、养殖）在**盈利顶点**时 PE 最低——"周期股要在高 PE（业绩差）时买，在低 PE（业绩顶）时卖"。
- 识别：利润同比增速已达历史极值、产品价格处于历史高位分位、行业产能仍在扩张 → 低 PE 是卖点信号而非买点。
- 反过来，周期股大面积亏损、PE 为负或极高时，若供给侧出清信号出现，反而是周期底部的观察窗口。

### 2. 价值毁灭型行业

- 特征：高资本开支 + 低 ROIC + 自由现金流常年为负，利润增长依赖持续融资稀释（典型：部分航空、部分面板、过度扩张的制造业）。
- 识别清单：近 5 年累计净利润 vs 累计增发融资额（用 query_warehouse_sql 无法直接查财报时，引用研报工具 eps 预测趋势并注明数据边界）；ROIC 长期低于 WACC；有息负债率持续攀升。

### 3. 分红陷阱

- 高股息率可能是"股价跌出来的"（分母塌陷）；更要警惕**不可持续的分红**：分红率超过自由现金流、靠借钱分红、大股东质押高企下的高额分红。
- 可持续性检查：经营现金流净额 / 净利润 是否长期 ≥1；股息支付率相对历史区间的位置。

### 4. 财务粉饰信号

- 利润高增长但经营现金流长期与利润背离；应收账款增速远超收入增速；存货异常堆积；
- 大存大贷（账上巨额现金同时巨额有息负债）；频繁更换审计机构；上市后业绩连续变脸。
- 这些信号出现时，PE 再低也应回避——**估值便宜不能对冲造假风险**。

### 5. 萎缩行业的"优秀公司"陷阱

- 行业总需求不可逆下滑（人口、技术替代），公司治理再优秀也只能赚"存量博弈"的钱，估值中枢系统性下移。
- 识别：行业收入连续多年负增长、公司市占率已高但天花板可见。此时低估值是常态而非错误定价。

## 鉴别流程（结合本工作台工具）

1. 先看行业属性：周期 / 成长 / 稳定价值 / 萎缩（决定用哪套估值尺）。
2. 业绩位置：当期利润处于历史什么分位（研报工具的 EPS 预测 + 近三年对比）。
3. 现金流与分红可持续性（数据不足时明确说明本地工具边界，引用研报观点并标注机构）。
4. 资金面佐证：北向/机构是否持续净流入（北向持续买入的低估值股，陷阱概率显著下降）。
5. 结论必须写明：这是"便宜的资产"还是"便宜的价格"——前者值得等，后者值得买。
